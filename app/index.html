Hotkeys work from any app: Ctrl+Alt+A answer · Ctrl+Alt+H hang up · Ctrl+Alt+M mute · Ctrl+Alt+W show Wego.

The address shown when you start the Wego Team Server on your Mac mini. Leave empty to share only between tabs on this computer. This setting is shared by all profiles on this computer.

How Wego connects: In the Windows app, UDP, TCP and TLS work with any SIP phone system, the same way MicroSIP does. WebRTC / WSS also works in a browser, but only if your provider has WebRTC enabled. Use the same account in either Wego or MicroSIP at a time, unless your provider allows two devices.
